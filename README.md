\# Ethereum 30-Day Network Activity Analysis



\## Project Overview



A blockchain data analytics project analyzing 30 days of Ethereum Mainnet network activity using real blockchain data.



\## Analytical Workflow



Ethereum Mainnet → BigQuery → GoogleSQL → Python/Pandas → Visualization → Insight



\## Data Source



Google Cloud BigQuery Blockchain Analytics Ethereum Mainnet dataset.



\## Tools



\- Google BigQuery

\- GoogleSQL

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Plotly

\- Jupyter Notebook/Lab
